# Collectible Telegram usernames and anonymous +888 numbers

Besides gifts, two other Telegram collectibles trade on Fragment as tokens on TON.

## Collectible usernames

A Telegram @username held as a token. The holder can put it on an account, channel or group, sell it at a fixed price, or put it up for auction. Usernames run from 4 to 32 characters. Four letter names exist only as collectibles, so short names behave like a separate market.

The cheapest listing is a poor guide to value here: many fresh names sit at Fragment's 7 TON minimum and rarely sell. Floors by length are more useful when they are measured from names that actually sold.

## Anonymous +888 numbers

Phone numbers starting with +888 that exist only on Telegram. You can sign up and log in with one, with no SIM card and no mobile carrier. People use them to keep a personal number off Telegram, to run several accounts, or as collectibles.
